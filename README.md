## About Us

**MBDTECH LTD** delivers mobile applications, websites, custom software and technology integrations for businesses and entrepreneurs. Our work spans **Flutter and Dart**, **native Android with Kotlin and Java**, **iOS application development**, **responsive websites**, and **AI-enabled product features**.

We work with clients on new product builds, improvements to existing applications, integrations, publishing assistance and ongoing maintenance. Engagements can be organized around a defined project, monthly development support or longer-term collaboration, depending on scope and availability.

This GitHub profile brings together selected technical examples and project showcases. The linked repositories are **portfolio samples**, not complete proprietary client or production codebases.

## What We Build

### Mobile Applications

- **Flutter / Dart:** cross-platform applications for iOS and Android, custom interfaces, navigation, state management and device integrations.
- **Native Android / Kotlin & Java:** Android UI, platform APIs, app performance improvements, maintenance and Google Play preparation.
- **iOS Applications:** iPhone/iPad experiences, platform-specific integrations, app testing and App Store submission support.
- **Existing App Modernization:** bug fixing, feature additions, UI refinement, dependency updates and ongoing support.

### Websites & Web Applications

- Company and service websites, landing pages and responsive web experiences.
- Frontend engineering with HTML, CSS and JavaScript; modern framework-based projects where appropriate.
- Progressive Web Apps (PWAs), API-connected websites and custom business workflows.
- Website maintenance, performance improvements, SEO implementation and deployment assistance.

### AI, APIs & Automation

- AI-assisted application features, conversational interfaces and content-generation workflows.
- Third-party API integration, backend connectivity and practical workflow automation.
- Secure integration design, with production credentials and private infrastructure kept outside public repositories.

### Launch & Long-Term Support

- Apple App Store and Google Play publishing and submission assistance.
- App review issue investigation and compliance-oriented updates.
- Website/app maintenance, issue resolution and iterative improvements.
- SEO and digital marketing support, including Google Ads-related services.
